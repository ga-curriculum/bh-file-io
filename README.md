## Learning Objectives
By the end of this activity, students should be able to:
1. Describe the entire ML life cycle (as far as we've learned in DSB, as it pertains to batch prediction and Kaggle submission)
1. Submit their batch predictions to Kaggle using proper data management skills

## Length
The activity takes about 50 minutes.

## Prerequisites
1. Knowledge of models in sklearn
1. Knowledge of transformers in sklearn
1. Knowledge of train-test split
