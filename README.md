# ![](https://ga-dash.s3.amazonaws.com/production/assets/logo-9f88ae6c9c3871690e33280fcf557f33.png) Breakfast Hour: File IO

## Learning Objectives
This is a standalone Breakfast Hour activity with the following learning objectives:

1. Learn to read/write plain text to files with the `with` keyword
1. Learn to read/write JSON files
1. Learn to read/write pickled model files

## Length
The activity takes about 30 minutes.

## Prerequisites
1. Basic Python knowledge
1. Very basic modeling knowledge (OLS is used once at the end)
